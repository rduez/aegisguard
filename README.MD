# 🛡️ AegisGuard — Antivirus & Protection Temps Réel

[![Version](https://img.shields.io/badge/Version-1.1.0-38bdf8?style=for-the-badge)](https://github.com/rduez/aegisguard/releases/latest)
[![Platform](https://img.shields.io/badge/Plateforme-Windows_10_%7C_11-0078D4?style=for-the-badge&logo=windows)](https://github.com/rduez/aegisguard/releases/latest)
[![Framework](https://img.shields.io/badge/.NET-Framework_4.8_/_8-512BD4?style=for-the-badge&logo=dotnet)](https://dotnet.microsoft.com/)

**AegisGuard** est une solution de sécurité Windows légère et moderne conçue pour protéger votre système contre les menaces grâce à un moteur d'analyse par empreinte **SHA256** et un module de surveillance active en temps réel.

🌐 **Site Officiel :** [aegisguard.gt.tc](https://aegisguard.gt.tc)

---

## 📥 Téléchargement & Installation

Pour obtenir la version officielle et sécurisée d'**AegisGuard**, ne téléchargez pas le code source brut du dépôt. Rendez-vous directement dans la section **Releases** de GitHub :

➡️ **[Lien direct vers la dernière Release Officielle](../../releases/latest)**

### Packages disponibles dans la Release :
* **`AegisGuard_Setup.msi`** : Installateur Windows standard (recommandé).
* **`AegisGuard_v1.0.0.zip`** : Archive contenant l'installateur `.msi` et `setup.exe` pour une vérification locale avant installation.

> ⚠️ **Remarque (Windows SmartScreen) :** AegisGuard étant un logiciel indépendant non muni d'un certificat d'éditeur payant, Windows peut afficher une alerte SmartScreen. Cliquez sur **"Informations complémentaires"** puis **"Exécuter quand même"**.

---

## ✨ Fonctionnalités clés

* 🔍 **Analyse par empreinte SHA256 :** Vérification rapide et rigoureuse des signatures de fichiers.
* ⚡ **Surveillance en temps réel (Real-Time Shield) :** Interception automatique des créations et modifications suspectes dans vos répertoires.
* ☁️ **Analyse Cloud :** Intégration de vérifications réseau/API pour identifier rapidement les exécutables douteux.
* 🪶 **Ultra Léger :** Conçu pour impacter le moins possible la mémoire RAM et les performances de votre ordinateur.
* 💻 **Compatibilité étendue :** Configuré en `Any CPU` pour tourner de manière optimale sur les architectures 32-bit (x86) et 64-bit (x64).
